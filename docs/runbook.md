# VisaPilot / VisaMate: запуск и репетиция

## Установка

Из корня репозитория, Python 3.12:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock -e '.[test]'
# Скопировать только если .env ещё нет:
test -f .env || cp .env.example .env
./scripts/run.sh
```

Адрес сайта: http://127.0.0.1:8000/ — существующий frontend с живым API.
Swagger: http://127.0.0.1:8000/docs, health: `/api/v1/health`.
Один Uvicorn worker; frontend и API используют один origin/cookie/CSRF.
Стандартный кабинет — `local_data/`, перезапуск сохраняет данные и сессии.
Остановка — **Ctrl+C в терминале запуска**. Повторный `./scripts/run.sh`
не удаляет БД. Не запускайте два процесса на одной БД для этой репетиции.

Для картинок и сканированных PDF нужен Tesseract с языками `rus` и `eng`:
`tesseract --list-langs`. Без него PDF с текстом обрабатываются, а у сканов
поля нужно проверить/заполнить вручную. Пять live-OCR тестов в таком окружении
пропускаются с явной причиной. Установка Tesseract описана в
[документации архива](../app/documents/README.md).

## Отдельный демокабинет

Команда создаёт **новый** `local_data_demo/`. Если каталог уже существует,
она откажет, сохранив его целиком. `local_data/` и существующий `.env` не меняются.

```bash
python scripts/demo_data.py seed --data-dir local_data_demo
VISAPILOT_DATA_DIR=local_data_demo VISAPILOT_PORT=8001 \
VISAPILOT_ALLOWED_ORIGINS='["http://127.0.0.1:8001","http://localhost:8001"]' \
./scripts/run.sh
```

Демосайт: http://127.0.0.1:8001/. Два вымышленных аккаунта:

- `sample_alice`, пароль `SAMPLE-Password-123`: три дела FR с good/bad/corrected
  PDF трёх типов; ещё одно дело с тем же good-паспортом для более поздних дат.
- `sample_bob`, тот же пароль: собственные профиль и дело JP, архив Alice недоступен.

Все оригиналы — существующие `demo/documents/*` с SAMPLE. Извлечение читает
байты PDF под одинаковым переименованным именем; manifest с готовыми фактами
не используется. Seed подтверждает извлечённые поля именно синтетических
образцов. Пользовательские документы требуют собственной сверки.

Опорная поездка 1–10 декабря 2026. В bad есть истёкший паспорт, другой владелец
выписки, неподходящий полис. В corrected эти ошибки исправлены в содержимом.
В good/corrected дата выписки 20 ноября 2026: до этой даты реальная проверка
честно предупреждает о будущем документе. Ни один набор не обещает полного
закрытия требований: все 12 сценариев partial и ready=false.

Репетиция через существующий UI:

1. Войти Alice, открыть профиль; второй паспорт/ВНЖ — явное «Нет».
2. Открыть bad и сравнить замечания с corrected. Открыть оригинал в архиве,
   извлечённые значения и подтверждения; сохранить поле и вернуться к делу.
3. Открыть good и дело с поздними датами: один паспорт, разный срок относительно
   поездки. Запустить настоящую проверку кнопкой на обзоре дела.
4. В разделе письма сохранить собственный текст и скачать .txt. После правки
   входного документа старый текст сохраняется с отметкой устаревания.
   Повторную генерацию можно вызвать через Swagger/API; текущий UI показывает
   последнее письмо и не содержит редактора истории всех версий.
5. В хронологии отметить фактический возврат паспорта: исход остаётся unknown.
   Для полученного решения отдельно указать approved/refused.
6. Выйти, войти Bob: чужих дел/оригиналов/писем нет. Перезапустить сервер:
   свои данные доступны; после logout старая сессия отозвана.

Генерация с AI по умолчанию выключена: письмо помечено template. Успешная
живая проба выполнена на `gpt-6.1-sol`, CLI `0.160.1`, через существующий
вход ChatGPT. Проверить повторно и затем включить явно:

```bash
python scripts/probe_ai.py --model gpt-6.1-sol
VISAPILOT_AI_ENABLED=true VISAPILOT_AI_MODEL=gpt-6.1-sol ./scripts/run.sh
```

Для SAMPLE-сервера к этим переменным добавить DATA_DIR/PORT/ALLOWED_ORIGINS
из команды выше. Startup не обращается к AI; новое письмо вызывает существующий
AIProvider. Локальные шаблоны могут кэшироваться; включение AI/смена модели
делает их устаревшими. AI ограничен композицией подтверждённых предложений,
подробнее в [handoff](letters-integration-handoff.md). При лимите/timeout остаётся
явно обозначенный шаблон. Новый API-ключ и платный fallback не используются.

## Проверки

```bash
python -m pytest -q
python -m pip check
python -m app.common.export_openapi --check
python tests/auth_http_smoke.py
python tests/rules_profile_http_smoke.py
python tests/integration/package5_http_smoke.py
python tests/integration/cases_events_http_smoke.py
node frontend/tests/smoke.mjs
```

HTTP-smoke поднимают собственные временные серверы/БД, проверяют перезапуск
и завершают процессы. Последний включает 12 стран, реальный архив, проверки,
письмо/правки/скачивание/событие, двух владельцев и сохранность.
`tests/integration/test_application_journey.py` дополнительно проверяет bad →
corrected, один паспорт в двух поездках, правку/удаление и маркированный reset.
AI timeout и отклонённый ответ проверяются явно названными контрактными
фикстурами в `tests/test_letters.py`, без выдачи их за живую модель.

Для настоящего JS ApiClient (Node.js с fetch/FormData), при запущенном
**отдельном** SAMPLE-сервере:

```bash
VISAPILOT_TEST_ORIGIN=http://127.0.0.1:8001 node frontend/tests/api-smoke.mjs
```

Он создаёт отдельного SAMPLE-пользователя, проходит login → профиль → дело →
PDF → подтверждение → проверка → письмо → правка/скачивание → событие → logout.
UI smoke проверяет 15 экранов в деморежиме; проверка ApiClient работает через
настоящий HTTP. Визуальная проверка браузером в сессии реализации недоступна.

## Явный сброс SAMPLE

Сначала **остановить SAMPLE-сервер Ctrl+C**. Затем:

```bash
python scripts/demo_data.py reset --data-dir local_data_demo --confirm DELETE_DEMO_DATA
python scripts/demo_data.py seed --data-dir local_data_demo
```

Reset требует специального маркера каталога, созданного seed. Без точного
флага, без маркера или для основного `local_data/` операция запрещена.
При реализации сбрасывались только временные каталоги тестов. Ваши
существующие данные не сбрасывались. Скрипт не является сбросом общего кабинета.

## Что ещё не проверяется

Маршрут/транзит TR/AE и остальных стран ждёт пакета 7 Вани: endpoints отвечают
503. Проверок наличия рейсов нет. Полнота официальных требований не достигнута.
Настоящий OCR требует Tesseract rus+eng. Frontend не имеет полного редактора
всех Scenario.questions и истории писем; эти операции доступны через API/Swagger.
Список фактических проверок и границы передачи — в
[letters-integration-handoff.md](letters-integration-handoff.md).
