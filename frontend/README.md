# VisaMate frontend

Статический адаптивный сайт для сценария из `../docs/`. Реализован на HTML, CSS и JavaScript без сборки и внешних зависимостей.

## Запуск

С backend из корня репозитория:

```bash
./scripts/run.sh
```

Откройте `http://127.0.0.1:8000`: сайт и API обслуживает один сервер.
SAMPLE-аккаунты и отдельная БД: [runbook](../docs/runbook.md).

Для просмотра только интерфейса без backend:

```bash
python3 -m http.server 8000 --directory frontend
```

Откройте `http://localhost:8000`. Если `/api/v1/health` недоступен, сайт запускается в явно обозначенном демо режиме. В нём используются вымышленные данные; изменения сохраняются только до обновления страницы, а содержимое загруженных файлов не хранится. Для работы с backend подавайте `frontend/` и `/api/v1` с одного origin, как описано в `../docs/contracts.md`.

## Экраны

- Главная с поиском по стране, континенту, Шенгенской зоне и типу въезда.
- Каталог 12 направлений и подробная страница со статусом источников.
- Регистрация и вход при подключённом backend, профиль и сравнение направлений.
- Список дел, создание дела, обзор с двумя независимыми показателями и Smart Checklist.
- Личный архив документов, просмотр и подтверждение полей, прикрепление к делу.
- Условия маршрута и пересадок, черновик письма, ручная хронология и уведомления.

Демо показывает интерфейс и переходы, но не подтверждает визовые правила, документы или допустимость маршрута. Продуктовый объём, модели и ограничения зафиксированы в `../docs/concept.md` и `../docs/contracts.md`.
